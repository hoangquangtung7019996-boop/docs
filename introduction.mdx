GVP Bridge is a desktop app that lets you generate AI videos and edited images from your Grok gallery without manually navigating Grok's interface. You select an image, choose a prompt, and click **Fire** — the app handles everything else. It connects to a dedicated browser session behind the scenes, drives Grok's generation pipeline automatically, and streams real-time progress back to the app while you keep working.

## How the two-part system works

GVP Bridge is split into two cooperating parts that run together whenever you use the app.

<CardGroup cols={2}>
  <Card title="The Brain — desktop app" icon="cpu">
    The window you interact with. It stores your gallery in a local database, manages active generation streams, tracks real-time progress, and issues every command to the browser. All logic lives here.
  </Card>
  <Card title="The Bridge — GVPChrome browser" icon="chrome">
    A dedicated Chromium profile called **GVPChrome** that runs quietly in the background. It stays logged into Grok, and the desktop app drives it remotely. You log in once; GVP Bridge takes it from there.
  </Card>
</CardGroup>

When you click **Fire**, the app arms itself with your prompt and settings, triggers Grok's native generation flow inside GVPChrome, intercepts the outgoing request, and replaces the payload with your configuration — all before the request reaches Grok's servers. The generation response streams back as live progress data that you can watch in the **GenerationMonitor** sidebar.

## Real-time progress tracking

The **GenerationMonitor** in the right sidebar shows up to five concurrent generations at once. Each entry displays a circular progress ring that fills as the generation advances. When a generation finishes, the ring becomes a playback indicator and a thumbnail preview appears on hover. If Grok flags a generation for moderation, the indicator switches to an error state immediately.
